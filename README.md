# LeXtom.sk — Nový web · Finálny balík

Tento balík obsahuje kompletný nový web LeXtom.sk pripravený na nasadenie do WordPress.

## Obsah balíka

```
/web/                  → ČISTÉ SÚBORY NA NASADENIE (HTML + /images/)
                         Toto použite na produkčné nasadenie do WordPress.
/nahlad/               → náhľadové súbory (obrázky vložené, samostatné)
/NAHLAD.html           → ⭐ ZAČNITE TU — otvorte v prehliadači pre vizuálny náhľad webu
/NAVOD-SK.md           → návod pre web-developera (slovensky)
/NAVOD-EN.md           → developer guide (English)
/README.md             → tento súbor
```

## Rýchly štart

1. **Pozrieť web** → otvorte `NAHLAD.html` v prehliadači a preklikajte sekcie.
2. **Nasadiť na WordPress** → použite priečinok `/web/` a postupujte podľa `NAVOD-SK.md` (alebo `NAVOD-EN.md`).

## 5 sekcií webu (SK/EN)

1. **Kto sme** — firma, manažér, vízia
2. **Odborný personál** — nábor zahraničných zdravotníkov
3. **VIP Care Technology** — VIP BED, osobný príbeh, ekosystém
4. **Distribúcia produktov** — katalóg + detail produktu
5. **Development** — rozcestník 2 investičných projektov

Jazyky: SK/EN (prepínač v navigácii). Ďalšie jazyky až vo finálovej fáze.
